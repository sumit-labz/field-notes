I was working on two ideas: the brand positioning software and Story Dojo, which is my main focus right now. The reasons I gave for switching from the brand positioning software to Story Dojo were many. The first one was that the brand positioning software is going to be a real money earner, because it has such terrific value for people all around the world, although I haven't even proven it yet. The second was that distribution for the branding software could be a challenge. You need to try it on another idea, and with Story Dojo you can build the video distribution, and you can fail on that, because I'm not very confident speaking on video itself.

Somehow I started wondering: while I give myself reasons not to pursue the first idea, I started thinking that I'll be at a loss if I don't pursue it. I know that right now I'm hyper-fixated on the Story Dojo idea because stories are so personal to me. It is giving me a huge dopamine high, the idea that I can go out and become a star on the internet, talking about movies and their breakdowns. That has more dopamine effect on me than the branding software. But this is not the first time in my life I've done that. I have done it multiple times. Internally I feel that I need some therapy for this, because if I keep doing it, something else will come up. Story Dojo will result in another idea. Then where will it lead?

Or maybe the path is that I could not discover more dopamine in the first idea, and it evaporated. I made it so hard. Maybe there were some stuck sessions where I made it more and more difficult instead of yielding dopamine in it, and it got shelved. As per the DBT technique, even if you feel stuck on something, give it 10 minutes and see where you can take it. I think that's one of the pieces of advice I have, but I still feel like consulting or looking at ADHD research to see if this behavior can be corrected. That creates some shame inside me. But at the same time my brain is also giving me reasons: no, you have not shelved it, you will get back to it. Anyway, I need to think about it for a few minutes and then decide where it is going.

I think I found the fundamental problem, why the positioning software is not able to kick off. Building something useful for people requires sequential steps. For example, to test the idea of the brand positioning software, I would have to build a landing page, talk with people, then build it, refine the software. But the brain which needs dopamine doesn't want to go through those logical steps. It doesn't like that approach, and this is the fundamental conflict I am running into. Until I solve this, I will not be able to get into it. For a long time I was trying to build the landing page but I wasn't able to. It led me in different directions, like typography, etc., but I could not pursue that direction either.

>> The brain which needs dopamine doesn't want to go through those logical steps.

Which means for an ADHD brain, a normal way of developing software will not work, and I have to come up with my own methodology, isn't it?

I found out that landing page iterations are something my brain will never be able to do. So I don't have to go that route; I'll have to go through the distribution route instead. Suppose I start writing about Stencil + Frame in public, as an experiment I'm conducting, and ask people: right now brand strategists are employed to do this job, so what if there's software that can do it using sequential steps? Do you think, with the help of software and AI, a product can be built that replaces an agency? I think I have to go this route rather than the landing page route, and set up a distribution-based way of thinking to build Stencil + Frame. This could be the answer to where I've been stuck.
