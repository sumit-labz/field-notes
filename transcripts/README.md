# transcripts/

Raw, pre-cleanup transcripts referenced by posts via the `transcript:` frontmatter
field (a bare filename in this directory). When a post sets it, the file renders
at the very bottom of the post page inside a collapsed `<details>` labelled
"before cleanup" — Space Mono, lighter ink, line breaks preserved, nothing else.

Plain text only. If the field is absent (or the file is missing), nothing renders.
